# v1.0.1 — Horse meadow haze

The Sasagamine horse now blends more softly into the distant landscape using the terrain palette and live camera-distance fog. Its ground shadow also fades with distance; the additional mist clears smoothly when approaching. Rabbit, fox and snake movement remain unchanged.

Verified all grazer motion states over 24,000 frames, shader material isolation, live atmosphere uniforms, and the working map with no observed browser console errors.

The ZIP contains the complete site. Extract it, run `python preview.py --port 8792` and open http://127.0.0.1:8792/. Existing known review findings are documented in CODE_REVIEW.md. Repository and release remain private.
